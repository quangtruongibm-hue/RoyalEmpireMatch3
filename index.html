🎮 Quản Lý Trò Chơi

Chọn một game để tải toàn bộ dữ liệu từ Firebase lên và chỉnh sửa. Nếu chọn “Thêm trò chơi mới”, form sẽ trống.

3 ảnh giới thiệu

Có thể nhập tên file trong GitHub, ví dụ royal-empire-1.jpg; đường dẫn images/royal-empire-1.jpg; hoặc URL ảnh từ website khác. URL GitHub dạng /blob/ cũng được tự chuyển sang raw.

3 video giới thiệu

Có thể nhập tên file trong GitHub, ví dụ royal-empire-1.mp4; URL MP4/WebM từ nơi khác; hoặc link YouTube. Video GitHub nên nhỏ vì GitHub không phải dịch vụ lưu video chuyên dụng.
